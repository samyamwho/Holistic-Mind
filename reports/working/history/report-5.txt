1 Progress to Date – Summary
Holistic Mind has moved from a research prototype to a fully deployed beta plat-
form. The project now offers account management, personalised onboarding, daily
check-ins across six dimensions exercise recommendations, somatic and breathing
practices, video and audio content, guided and free-form journaling structured psy-
choeducational courses, a record of progress reminders and an administration dash-
board. Firebase was replaced by a custom backend written in Node.js, PostgreSQL
and TypeScript. A separate Python recommendation service and cloud-based media
storage support the system. All main mobile paths, backend APIs, the database,
the recommendation engine, the administration platform and the production de-
ployment are now working.
2 Artefact Design and Development
2.1 Implementation and Current State
The mobile app is built with Expo React Native and TypeScript. It uses an clear
visual style with soft colours, rounded cards and minimal clutter. Navigation is
arranged around Home, Explore, Journal and Library with History inside the Pro-
file. Authentication includes email verification, password recovery, secure sessions,
Google sign-in, logout and account deletion.

2.2 Analysis and Reflection
A key learning point was that technical features must be matched by privacy, safety,
usability and maintainability. Replacing Firebase needed a lot of redevelopment. It
gave stronger control over relational data, authentication, recommendations and
content management. Repeated interface testing showed that small spacing, card
size, icon and text-wrapping problems have an impact on usability. The recom-
mendation engine also showed that advanced AI is not always better; controlled
suitability rules, explainability, privacy and fallback behaviour are essential. Work-
ing on authentication, storage, deployment and iOS integration improved full-stack
debugging and systems thinking.
