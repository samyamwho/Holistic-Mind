HOLISTIC MIND — PROGRESS REVIEW DIAGRAMS

The diagram set contains four report-ready figures. Each figure is supplied as
an editable SVG for documents and a high-resolution PNG for presentation slides.

1. 01-system-architecture.svg
   Caption: Holistic Mind production architecture. The mobile application and administration dashboard communicate with a protected backend API, which coordinates PostgreSQL, the private recommendation service, object storage, email delivery, and native device services.

2. 02-user-workflow.svg
   Caption: Holistic Mind end-to-end user workflow. The central daily loop moves from check-in to recommendation, practice, and feedback, while Explore, Journal, Library, and History provide user-led support and long-term engagement.

3. 03-recommendation-engine-workflow.svg
   Caption: Hybrid recommendation workflow. Authenticated context is pseudonymised and ranked through suitability rules, semantic relevance, behavioural evidence, and diversity control before feedback is returned to future recommendation requests.

4. 04-content-and-deployment-workflow.svg
   Caption: Content administration and deployment workflow. Authorised administrators manage structured content and media, while the promotion process transfers only managed content records and referenced assets—not private user information.

USAGE

- SVG is a vector format and remains sharp when resized in Word, Google Docs, PowerPoint, or presentation software.
- PNG files are 1600 pixels wide and ready to place directly into slides or a PDF report.
- Keep each figure at its original aspect ratio.
- For an academic report, place the caption immediately below the diagram and refer to it in the surrounding paragraph, for example: “The production architecture is illustrated in Figure 1.”
- The diagrams use the same visual family as the Holistic Mind application: warm neutral backgrounds, muted rose, sage, lavender, and sand accents.
- The diagrams describe the implemented project as of 2 September 2026.
